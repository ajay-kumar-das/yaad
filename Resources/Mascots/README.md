# Mascot asset package

Production Momo artwork belongs in this folder. The app currently contains a SwiftUI vector fallback so the reminder and Live Activity remain functional before final art arrives.

Follow `Docs/CONTENT_AND_MASCOT_CONTRACT.md` and update `momo-core.manifest.example.json` when adding assets. Referenced asset IDs must exist in the app and widget targets. Base assets are bundled and may not depend on a download.
